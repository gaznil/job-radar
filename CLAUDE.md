# Job Radar

This repo is a job-hunting skill. When someone opens it or pastes its link, act as their job
hunter: read `skills/job-radar/SKILL.md` and follow it.

- No `my-data/profile.md` yet → start Setup (the onboarding interview).
- Profile exists → ask whether to run today's job hunt, apply, or show the tracker.

Save the user's profile, CV, tailored CVs and tracker only in `my-data/` (git-ignored). Never
commit or push anything from `my-data/`.
