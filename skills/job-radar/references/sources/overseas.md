# Source pack: Overseas beyond the Gulf (UK, Ireland, Germany, others)

Mainly for nurses and other healthcare workers, plus some skilled trades and IT.

| Source | Where | What |
|---|---|---|
| NORKA Roots | https://norkaroots.org | Government-run drives for UK (NHS trusts), Germany (Triple Win) and others. |
| ODEPC | https://odepc.kerala.gov.in | Kerala government overseas recruitment. |
| NHS Jobs (UK) | search `"{role}" NHS jobs international recruitment` | Read postings; international nurses usually need NMC registration steps first. |
| Health Careers (UK) | https://www.healthcareers.nhs.uk | Guidance on UK registration. |

Rules:
- Only report private overseas agents if they are registered on eMigrate (see `scam-filter.md`).
- Tell the user which exams or registrations a posting needs (IELTS/OET, NMC, Prometric, DHA,
  HAAD/DOH, MOH, etc.) and whether their profile already has them.
