# Source pack: Remote

Only for users who chose remote work.

```
site:jobs.lever.co "{role}" remote India
site:boards.greenhouse.io "{role}" remote India
site:jobs.ashbyhq.com "{role}" remote
"{role}" remote "India" hiring
```

Boards: Wellfound (startups), Cutshort, LinkedIn (filter Remote, read only), Indeed India
(filter Remote).

Check every remote posting for: does it hire in India (many say "US only"), pay currency,
working hours, and whether it is contract or full-time. Remote "data entry", "typing" and
"task" jobs that pay per task are almost always scams; block them.
