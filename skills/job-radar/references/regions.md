# Picking regions by role

Start from where the user said they will work. Then suggest regions where their role is in real
demand, and let them say no. Kerala is always included if they live in Kerala.

| Role family | Suggest | Source packs |
|---|---|---|
| Software, IT, data, QA, design | Kerala IT parks, Bangalore, Chennai, Hyderabad, Pune, UAE, remote | `kerala`, `india` (IT boards + company hiring systems), `gulf`, `remote` |
| Nurse, lab tech, pharmacist, physio, other healthcare | Kerala hospitals, UAE, Saudi, Qatar, Kuwait, Oman; UK / Ireland / Germany via government recruiters | `kerala`, `gulf`, `overseas` (NORKA, ODEPC first) |
| Accountant, finance, admin, HR, office staff | Kerala, metros, UAE, Saudi, Qatar | `kerala`, `india`, `gulf` |
| Sales, marketing, customer service, BPO | Kerala, metros, UAE | `kerala`, `india`, `gulf` |
| Driver, technician, electrician, plumber, welder, construction, hospitality, retail, security | Kerala, Gulf (all six) | `kerala`, `india` (Apna, WorkIndia), `gulf` (government recruiters + verified agencies only) |
| Teacher, lecturer | Kerala, Gulf schools, India | `kerala`, `india`, `gulf` |
| Freshers (any field) | Kerala walk-ins, IT parks, internships, metros | `kerala`, `india` (Internshala, walk-ins) |
| Government jobs | Kerala PSC, central exams, CMD Kerala contract jobs | `kerala` (government section), `india` (NCS) |

Rules:
- Gulf blue-collar and healthcare: prefer government recruiters (NORKA Roots, ODEPC) and agencies
  registered on eMigrate. Run the scam filter strictly.
- Remote roles: only if the user is comfortable with written English and has a laptop and
  stable internet. Ask.
- Save the chosen packs and countries in the profile under `regions:`.
